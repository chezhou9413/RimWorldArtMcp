# RimWorld 贴图参考与生图

使用 `rimworldArt` MCP。它负责参考、说明和确定性的本地处理；生图由当前 Codex 的内置 `image_gen` 完成，无需 Packy 或 API Key。

## 选择参考

- 用 `search_references` 搜索中文名称或别名。默认 `styleFamily=vanilla`。二次元种族使用 `styleFamily=anime`，先找到候选，再按返回的 `race`、体型与部件筛选；`all` 仅用于跨风格浏览。
- 用 `get_reference` 实际看图；需要方向组时设置 `includeGroup=true`。返回的 `absolutePath` 是当前安装位置的真实路径，不要猜测开发者电脑上的路径。
- 先分清 `main/template/component/mask/ui`。炮塔顶部不是完整建筑，面部部件不是完整头像，遮罩不是配色参考。
- 原版风格以同类剪影、克制的明暗和小尺寸辨识度为准。植物可以使用有色边缘；UI 不能统一加黑边。
- 二次元种族以自己的头身比例、部件层级、线宽和占位为准。原版、不同种族、不同角色或体型的模板不能直接混用。头部是否已含五官必须看图并查元数据。

## 准备与生图

调用 `prepare_texture_brief`，明确主参考及每张图片的 `style`、`structure` 或 `template` 用途。一次只准备一张成品；其他方向可作为结构参考。尺寸默认沿用主参考，也可成对指定宽高。

绘制 Pawn 或其身体、服装、头部、头发、BodyAddon、面部部件时，提示词必须明确标记“禁止出现手部”：不画手掌、手指、拳头、握持武器的手、手套手形、机械手或手形夹爪，不为持械或姿势补出手部。原版、二次元种族、自定义 Pawn 和机械体均遵守；不要在设计描述中要求与此冲突的手部结构。

实际查看需要传入的参考图后，调用内置 `image_gen`，使用工具返回的提示词、真实参考路径和 `transparent_background=true`。参考拼图中的底色、标签和多格布局都不是输出要求。不能让 MCP 代为调用这个内置工具。

生成工具没有目标尺寸或保存路径参数时，不虚构参数。取得实际生成文件，再使用 `process_texture` 输出到用户指定位置或当前 Mod 的正确 Textures 目录。保留真正的 Alpha，不默认用绿幕抠图。内置生图不可用时明确报告，不自动切换收费接口。

## 检查与加粗

- 用 `inspect_texture` 或处理结果中的对比图查看原画布、128 和 64 缩略预览。数值检查只说明透明度、尺寸、占位与触边，不能证明美术质量。
- Pawn 贴图必须看图确认没有手部；出现手掌、手指、握持手或机械手时不能验收为成品，应通过生图编辑去除并恢复正确轮廓。
- `outlineExpandPx` 是额外增加的最终输出像素，不是总线宽。默认 0；确认过细后再增加，并检查细枪管、发梢、领口等是否黏连。
- 内线只能提供 `lineMaskPath` 明确选择：白色为线、黑色排除、透明度参与权重；`innerExpandPx` 控制增量。没有掩膜时用内置生图编辑，不把黑色填充或阴影当成线稿。
- 身体、头部、服装及挂接部件需要原模板时，传 `templateReferenceId` 或 `templatePath`。模板只限制 Alpha，不复制模板颜色，也不会补出源图缺少的部分。
- 多方向保留各自模板画布、中心和锚点，不逐张裁切居中。建筑方向图可能交换宽高，应依据真实参考。
- 成品检查通过后保存到任务目标；除非用户要求替换，否则使用新文件名。工具不会覆盖参考图库或输入原图。

## 让图库成长

用户要求收录参考，或本次任务已明确选定值得复用的参考时，使用 `add_reference_group` 复制图片进图库。录入前实际查看各方向并核对来源，不能只按文件名收图。

每组对应一个种族/角色、体型和部件，包含完整可用方向；缺失方向如实保留，不假造。提供稳定 `groupKey`、中文名称、别名、`styleFamily`、`category`、`role`、种族和来源。说明前后层、是否含五官、保留的留白、线条与上色要求。来源只写核实的信息；不把个人绝对路径或凭据写进可分享元数据。

录入后用 `get_reference` 看整组。用 `update_reference_group` 补充发现的限制、别名或风格说明；数组字段是整项替换，先读取现有内容后合并。图片替换使用新组名，不改掉既有参考。生成草稿不自动入库，选定成品可按 `source.kind=generated` 录入。

图库变化立即可检索，不需要重建全盘索引。分享时包含项目的 `library` 目录；若配置了外部图库目录，按项目 README 的说明一并导出。
